## 两条用户流程

### 整层编辑

选择合格普通像素层 → 输入要求和选择可编辑模型 → 只读取本层 → 生成候选 → 选择一张预览 → 再次验证源状态 → 同父级原位创建结果层 → 显示结果并隐藏原层。原层像素与层级保留，一次历史撤销完整恢复。

沿用初始设计的 RGB8/sRGB、普通混合、无蒙版/样式/剪贴关系等资格要求。生成过程不改变 PSD；目标在提交时锁定。

### 文字生图

输入文字和选择生图模型 → 生成候选 → 选择一张预览 → 应用到锁定的 Photoshop 目标文档新图层。已有图层的显隐保持原样。

首版应用需要已打开的合格文档；文档尺寸变化或关闭后保留导出，不猜测新目标。采用等比适配画布并居中，不拉伸比例；在预览中显示生成尺寸和实际放置尺寸。新增文档向导不列为首版验收项。

## 本轮对初始设计的变更

| 初始设计 | 当前决定 |
|---|---|
| 一个真实模型配置验收 | Cangyuan 支持的全部图像模型纳入接入与验收 |
| 只有整层编辑 | 增加文字生图，支持仅文生图模型 |
| 始终一张候选 | 允许服务原生多候选，最终一次只应用一张 |
| OpenAI multipart 编辑作为首个适配器 | 以 Cangyuan 实际统一协议及逐模型字段为准 |
| 固定初始模型范围 | 发布前更新清单，新增图像模型也纳入首版 |
| API Key 只存服务内存 | 正式 UI 保持该策略；开发者可自行在 Git 忽略的本地环境中配置测试 Key |
| 无已确认测试预算 | 所有开发真实模型测试累计上限为人民币 30 元 |

“全部模型”指图像模型接入，不包括聊天、音频和视频，不代表每个模型都支持图层编辑或透明输出。每个模型按真实能力提供入口。公开目录、当前 Key 可见、实现完成和实测通过分开记录。

## 素材与费用

源图保留本地。首轮采用程序生成的色块、棋盘和透明边缘素材；需要语义生图测试时使用无私人内容的图。用户允许使用本地原图或由开发方生成测试素材，没有授权新增第三方图片存储。

远端图像编辑必然需要把本次图层的必要内容交给所选服务；本机文件路径本身不能被远端读取。优先验证 Cangyuan 本地文件上传或服务明确允许的内嵌输入。现有公开文档只保证 HTTPS URL 输入，上传链路尚待核实；这项由 #7 跟踪，不伪称已支持直接文件上传。

30 元为本项目真实模型测试累计上限，不是每次或每个模型 30 元。免费本地测试优先；实际计价、Token 权限、费用预留和状态未知任务的处理见验收计划。
