# 安装与使用（开发版）

这是面向本机开发/试用的安装说明，不是 Adobe 应用商店产品。当前版本的真实 Photoshop 图层往返和真实 Cangyuan 付费生图仍可能受环境或 Key 限制；默认请使用 **Mock（开发）**。

## 你需要准备

- Windows
- Node.js 24（不要用 25）
- pnpm 10.33.0
- Photoshop 26 或更新版本，并打开 **UXP Developer 开发者模式**
- 本仓库的一份干净拷贝

不需要 Cangyuan Key 也能跑通 Mock 整层编辑和文字生图。不要把 API Key、配对 Token 发到聊天或 GitHub。

## 安装

在项目目录：

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm plugin:build
pnpm bridge
```

本地服务只监听 `127.0.0.1:47833`。启动后会在 `.local/bridge-session.local.json` 写入本次随机 Token。按 `Ctrl+C` 停止；正常停止会删除该会话文件。

开发安装包（不含源码、Key、用户图片、`node_modules`）由 `pnpm pack:dev` 生成，位于 `artifacts/photoshop-ai-0.0.1-<git>.zip`。

## 在 Photoshop 中加载插件

1. 打开 UXP Developer Tool，把插件目录指到仓库里的 `apps/plugin/`（或安装包解压后的 `plugin/`）。
2. 加载面板 **AI 图层编辑**。
3. 打开面板 → 设置 → 粘贴本次 Token → 连接本地服务。
4. 协议保持 **Mock（开发）**，先不要填写真实 Key。

浏览器里的 `apps/demo/index.html` 带有 **DEMO / 模拟宿主** 横幅，只能看界面，不能当作 Photoshop 验收。

## 使用

1. 打开一份**专门用于试验**的 RGB/8 位/sRGB 文档，不要用你正在做的客户稿。
2. **整层修改**：选中一个普通像素图层，填写修改要求，生成候选，只选一张再应用。成功后会在源层正上方新建结果层，并隐藏源层。可用 Photoshop 历史一次撤销。
3. **文字生图**：不读取源图层。结果按比例适配画布并居中，不会改其他图层的显隐。
4. 选区和指定蒙版是后续版本，按钮是禁用的。

若提示图层不受支持（智能对象、蒙版、效果、锁定、非普通混合等），这是首版限制，不会自动栅格化你的原稿。

## 配置检查的三种状态

它们不是一回事：

- **格式检查通过，尚未鉴权**
- **鉴权通过，尚未验证图像编辑**
- **真实生图已验证**（尚未完成前不会出现）

Mock 下最多显示 “Mock 图像路径已验证，不是真实模型验收”。绿色成功文案不会用来表示还没做的验收。

## 卸载与清理

1. 在 UXP Developer Tool 卸载/删除本插件。
2. 停止本地服务。
3. 删除 `.local/`（会话和测试素材）以及你解压的安装包目录。
4. 不要把 `.env`、Token、用户 PSD 拷贝到别处或提交到 Git。
